# Einzbern 4.1.0: Empirical acceptance principles

- Reuse successful full Core results when test file names contain diagnostic
  words, while preserving checks for actual errors and warnings.
- Reconcile autonomy, batching, unattended commands, reporting and design
  authority around observed behavior, focused implementation self-checks and
  acceptance evidence. Preserve approved roles, release dependencies and criteria.
- Distinguish reproduced defects from static findings and hypotheses. Limit
  blocking review findings to demonstrated impact or explicit contract violations;
  reuse applicable results and stop repeating checks without new evidence.
- Preserve minimal-change boundaries and existing authorization. Mechanical
  extraction and validation do not require additional model review stages.
