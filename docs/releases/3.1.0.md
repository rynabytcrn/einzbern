# Einzbern 3.1.0

Einzbern and Mana Orchestrate ship in lockstep at 3.1.0.

### Shared library and project memory

- Store multiple projects in one shared `Ether` library while retaining stable
  project identities, project configuration, original native history and knowledge
  bodies. Shared-library recall separates project records and retains global cards.
- Consolidation verifies source histories and rejects conflicting identities or
  changed source copies. Verified cleanup preserves relocation receipts and
  historical evidence before retiring the exact old library roots.
- Managed-document health checks use the selected project's explicit registry
  binding, so another project's digests or pending sections do not affect it.

### Installation, restore and device runtime

- `Ether` is the shared library folder name. Its parent is chosen by the user and
  may be on a local disk, an external disk or in a synchronization folder; cloud
  detection does not restrict the location. Later projects reuse the saved library.
- New installations and restores keep device-specific cache, locks and backups
  under `Ether/.einzbern/<device-id>/`. Device identity, the registry, host policy
  and installed engine versions remain local to each device.
- Storage relocation has a plan and an explicit apply step. Same-volume moves and
  verified cross-volume copying preserve data and support interrupted-operation
  recovery; changed or unowned destinations are refused before source cleanup.

### Compatibility and upgrades

- This release supports library format 3 for shared-library provenance and scoped
  chain identities. Existing format-1 and format-2 libraries remain readable;
  they are not silently consolidated or upgraded by this release.
- Update every device that will use a shared format-3 library before migration.
  The previous public 3.0.0 engine supports format 2 and cannot open format 3.
  Review the migration plan and keep a verified library/device backup first.
- Rolling an engine back does not downgrade a format-3 library. Recovery with an
  older engine requires a compatible preserved library; do not rewrite event
  history or lower a manifest's format number to bypass a reader refusal.
- Local 3.0.3, 3.0.4 and 3.0.5 installation candidates were not public releases.
  The public comparison baseline for 3.1.0 is 3.0.0.

### Documentation and lockstep delivery

- Engine and helper installation documentation uses the same `Ether` naming and
  user-selected parent rule, including existing `.ether` library compatibility.
  Library README refresh preserves the previous generated README as evidence.
- Einzbern and Mana Orchestrate use the same release version. The engine release
  supplies one archive containing the engine and Skill, with its adjacent SHA-256
  file; the helper release links to that archive. Full notes remain available by
  functional module in the Wiki.

See the [shared-library contract](../../specs/shared-library-v1.md) for layout,
provenance and migration boundaries.
