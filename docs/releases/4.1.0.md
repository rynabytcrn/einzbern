# Einzbern 4.1.0

Einzbern and Mana Orchestrate ship in lockstep at 4.1.0.

### Managed harness updates

- Refresh existing registered instruction outputs when updating or rolling back
  the engine. The selected engine renders navigation, enabled built-in rules and
  variables, so updates use its catalog instead of the initiating process's text.
- Preserve Owner text, local edits, user-owned or removed sections, disabled
  rules, generation-disabled outputs and independent dot targets. Report pending
  sections and unavailable outputs individually while refreshing other outputs.
- Detect catalog body corrections even when a rule's version is unchanged.
  Rule listing reports outdated text and doctor distinguishes it from user edits.
- Complete upgrades initiated by older update code through the newly installed
  managed writer, as documented in Mana's update guide.

### Empirical acceptance principles

- Reuse successful full Core results when test file names contain diagnostic
  words, while preserving checks for actual errors and warnings.
- Reconcile autonomy, batching, unattended commands, reporting and design
  authority around observed behavior, focused implementation self-checks and
  acceptance evidence. Preserve approved roles, release dependencies and criteria.
- Distinguish reproduced defects from static findings and hypotheses. Limit
  blocking review findings to demonstrated impact or explicit contract violations;
  reuse applicable results and stop repeating checks without new evidence.
- Preserve minimal-change boundaries and existing authorization. Mechanical
  extraction and validation do not require additional model review stages.

### Recoverable configuration backups

- Add recoverable remote-staged configuration backups with exact verified
  manifest binding and bounded metadata throughout the retention lifecycle.
- Recover staged bytes using the original bound plan and preserve safe local
  retirement recovery when no new allocation is needed.
- Distribute the generated backup contract and host-specific usage guidance
  through the matching Mana release.
