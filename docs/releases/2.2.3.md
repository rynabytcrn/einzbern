# Einzbern 2.2.3

This is a local source candidate for the engine model policy work in INIT-056. It has not been
published or installed. Its version is distinct from the installed 2.2.2 cloud baseline.

The engine now has a device-level model policy store partitioned by host. The formal
`engine-model-policy-catalog` and `engine-model-policy-set` commands expose its source, revision,
digest and audit metadata. Writes require an actor and a matching Owner decision; the selected
host policy is written atomically, preserving other hosts. The write receipt uses the persisted
snapshot read while the device lock is held.

`settings-catalog` distinguishes the engine policy from legacy project settings. Atelier's
model-policy API uses the formal CLI boundary and the existing access checks. Visible Atelier
configuration, dispatch consumers and global Codex policy application remain unfinished; the
backend implementation alone does not satisfy STORY-551 through STORY-553. No project model
settings or non-Codex policy are changed by preparing this candidate.

The privacy classifier adds only the three reviewed compiled owner-line members from the actual
2.2.2 package. A 2.2.3 package remains unclassified until its actual member and source evidence is
reviewed. Verification receipts and the final package identity are recorded separately.
