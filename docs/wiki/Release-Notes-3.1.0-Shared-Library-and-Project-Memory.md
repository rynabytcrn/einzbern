# Einzbern 3.1.0: Shared library and project memory

[Release notes](Release-Notes.md) › [Einzbern 3.1.0](Release-Notes-3.1.0.md)

Next: [Installation, restore and device runtime](Release-Notes-3.1.0-Installation-Restore-and-Device-Runtime.md)

- Store multiple projects in one shared `Ether` library while retaining stable
  project identities, project configuration, original native history and knowledge
  bodies. Shared-library recall separates project records and retains global cards.
- Consolidation verifies source histories and rejects conflicting identities or
  changed source copies. Verified cleanup preserves relocation receipts and
  historical evidence before retiring the exact old library roots.
- Managed-document health checks use the selected project's explicit registry
  binding, so another project's digests or pending sections do not affect it.
