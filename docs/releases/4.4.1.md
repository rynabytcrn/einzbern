# Einzbern 4.4.1

Einzbern and Mana Orchestrate ship in lockstep at 4.4.1.

### Codex worker dispatch

- Keep implementation workers on the native subagent entry in the approved
  two-conversation workflow. Scoped dispatch preparation and peer receipts reject
  independent conversation creation or forks presented as worker dispatches.
- Deny a registered coordinator's incorrect create or fork before the tool runs,
  including native calls inside code mode. Ordinary unbound conversations and
  correctly associated native subagents retain their normal behavior.

### Durable coordinator roles and recovery

- Keep registered main/coordinator roles across turns, summaries, process restarts
  and subsequent batches. A terminal batch does not automatically retire its role.
- Report missing, unreadable, malformed or mismatched material for a known role
  as a visible dispatch failure. Recover or retire bindings through the existing
  governed peer-record lifecycle rather than silently treating them as unbound.

### Installation and native hook readiness

- Check actual native PreToolUse registration, enabled state, current trust and
  role recovery during the supported installation and maintenance workflow.
  Missing, disabled, untrusted or unavailable observations do not report the
  protected coordination mode as ready.
- Ship the same workflow guidance and readiness checks through the generated
  Mana Orchestrate skill, fresh installation, update, repair and doctor. Preserve
  user-owned hooks, configuration and model policy; keep SubagentStop retired.

### Compatibility and verification

- Retain historical v1 peer records as historical evidence while using the scoped
  worker contract for guarded dispatch. Keep existing model fallback, quota,
  project admission, polling and terminal handoff behavior.
- Verify direct and code-mode denial, a real native child, durable role recovery,
  and isolated installation on the observed macOS Codex CLI host. Protection
  requires an enabled, trusted installation and registered roles; this evidence
  does not claim coverage after removal of those prerequisites or on other hosts.
