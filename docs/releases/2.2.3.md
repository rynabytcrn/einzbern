policy and quality-audit work. Its version is distinct from the installed 2.2.2 baseline. No
owner-device installation or host-default model change is implied by this PR.

and lock order, hook rollback reporting, and planned rollback/engine-pointer publication.

and retain the rollback receipt. Historical project policy/events remain readable, not runtime
policy authority. Device model policy and local path bindings require explicit configuration;
shared paths/variables must satisfy the portable/export contract. No automatic historical path
conversion, private-variable export, event rewrite or blanket reader-floor increase is claimed.
Review a governed projection refresh plan before updating generated shared files.
