# Einzbern 3.0.5

Local installation candidate; no tag or remote publication.

The shared-library folder is named `Ether`. Its parent is chosen by the user;
cloud-provider detection is a suggestion, never a location requirement. Setup and
restore retain the chosen shared library for later projects. Native records keep
the established `akasha`, `crest`, `config` and `artifacts` names. Runtime data is
separate per device in `Ether/.einzbern/<device-id>/`; device identity, host policy
and installed engines remain local. Existing `.ether` libraries remain readable.

`storage-consolidate` validates history, file digests and exact owned roots before
retiring old directories. Its durable receipt supports retry. The previous README
is archived when `library-readme-refresh` updates it after acceptance.
